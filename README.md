# Crowdfunding Project

Платформа для аренды земельных участков с возможностью инвестировать или резервировать поля.

## Netify


## Стек

- **React 19** 
- **Webpack 5**
- **React Router**
- **Redux Toolkit**
- **RTK Query**
- **Яндекс.Карты**
- **CSS**

## Запуск

```bash
npm install
npm start
```

Откроется `http://localhost:3000`.

### Сборка

```bash
npm run build
```

Результат — в `dist/`.

## Данные

- **DummyJSON** (`https://dummyjson.com`).
- **Ранчи** — мок-данные через `ranchesApi`.
- **Пользователь** - мок-данные через `userApi`.
